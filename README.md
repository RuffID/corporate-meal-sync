# Обмен СКД → iikoCard → 1С

Проект связывает систему контроля доступа (СКД), корпоративное питание в iikoCard
и учёт в 1С. Он пополняет кошельки по ежедневному списку пропусков и передаёт
фактические списания для дальнейшего учёта.

## Как проходит обмен

1. СКД формирует файл с пропусками за день.
2. Проект получает файл с сервера обмена. Если файл передали вручную, его можно
   загрузить локально.
3. По каждому пропуску определяется номер карты и её действующий владелец в iikoCard.
4. При отсутствии карты создаётся гость. При необходимости ему назначаются
   категория и программа корпоративного питания.
5. На нужный кошелёк начисляется сумма, заданная в настройках.
6. Списания за выбранный день выгружаются в файл для 1С и отправляются на сервер обмена.

## Основные правила

- За одну дату одна карта получает одно подтверждённое пополнение в рамках
  настроенных организации и кошелька.
- Удалённые и заблокированные гости не пополняются. Неоднозначные карты и дубли
  требуют проверки оператором.
- Уже назначенная действующая категория повторно не назначается.
- Если результат начисления неизвестен, повторное начисление блокируется до сверки.
- При ошибке обработка останавливается. Уже выполненные начисления сохраняются.
- Перед повторным запуском за день, обработанный старой версией, нужно сверить
  реальные начисления.
- Если списаний за день нет, файл для 1С не отправляется.

Защита от повторных начислений использует локальный журнал. Его нужно сохранять
и использовать общую папку данных для обычной и ручной загрузки.

## Что доступно оператору

Можно загрузить пропуска с сервера или из локального файла, выгрузить списания
за день и посмотреть отчёт за период. Есть графический интерфейс и консольные команды.

По умолчанию загрузка пропусков выполняется за сегодня, консольная выгрузка
списаний — за вчера. В графическом интерфейсе дата выгрузки выбирается отдельно.
