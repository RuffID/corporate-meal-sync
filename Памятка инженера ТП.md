# Памятка инженера ТП: обновление и повторное пополнение

Используйте эту памятку, если импорт прервался и нужно пополнить оставшихся гостей.
Команды выполняются в PowerShell на компьютере клиента под тем же пользователем,
что запускал обмен. Обычно права администратора для этих действий не нужны.

В примерах рабочая папка — `C:\Users\iiko\Desktop\corporate-meal-sync`,
дата пополнения — **08.10.2026**. Если путь или дата другие, замените их в командах.
Пути к данным ниже соответствуют стандартному размещению в `app\main`.
Если в рабочем `config.local.json` указан другой `data_dir`, папки `Csv`, `State`
и `Logs` находятся внутри него. Используйте прежние настройки и папку данных.

## 1. Обновить программу

Дождитесь завершения работающего импорта. Не обновляйте файлы во время обработки
и не запускайте ручной импорт одновременно с заданием планировщика.
Перед обновлением сохраните резервную копию папки `State`.
Изменения должны быть заранее закоммичены и отправлены в ту ветку репозитория,
которая используется на компьютере клиента.

```powershell
Set-Location -LiteralPath 'C:\Users\iiko\Desktop\corporate-meal-sync'
git pull --ff-only
```

Продолжайте после успешного обновления. Сообщение `Already up to date` означает,
что новых изменений в отслеживаемой ветке нет. Если исправление ожидалось, проверьте
с разработчиком, отправлено ли оно в нужную ветку.
Если Git сообщает об ошибке, конфликте или локальных изменениях, передайте вывод
разработчику. Не используйте `reset --hard` или `clean` для принудительного обновления.

## 2. Проверить локальный CSV

Повторный запуск ниже **не скачивает файл с SFTP**. После обычного импорта
скачанный файл должен уже лежать здесь:

```text
C:\Users\iiko\Desktop\corporate-meal-sync\app\main\Csv\20261008-SKD-IIKO.csv
```

Проверка наличия файла:

```powershell
Test-Path -LiteralPath 'C:\Users\iiko\Desktop\corporate-meal-sync\app\main\Csv\20261008-SKD-IIKO.csv'
```

`True` — файл существует. Если `False`, получите у ответственного за СКД или скачайте
с SFTP исходный файл пропусков **за нужную дату** и положите его в указанную папку.
Имя должно быть `YYYYMMDD-SKD-IIKO.csv`: например, `20261008-SKD-IIKO.csv`.
Не подставляйте файл другого дня и файл выгрузки `IIKO-1C`.

Формат: UTF-8, одна строка — один идентификатор пропуска из 16 HEX-символов,
без заголовка. Сохраняйте содержимое исходного файла; не удаляйте уже обработанные
строки вручную. Скачивание выполняется используемым у клиента SFTP-клиентом.

## 3. Повторить пополнение за нужную дату

```powershell
& 'C:\Users\iiko\Desktop\corporate-meal-sync\app\skdtoiikowithoutftp.bat' --date 2026-10-08
$LASTEXITCODE
```

`--date` — дата пополнения и входящего CSV. Указывайте её явно, особенно при повторе
за прошлый день. Этот запуск читает локальный CSV и обращается к iikoCard;
доступ к iikoCard по сети необходим. Выгрузка списаний в 1С этой командой не выполняется.

Сохранённые начисления со статусом `confirmed` будут пропущены. Операции `sending`
и `unknown` проверяются по транзакциям iiko; без подтверждения повторное начисление
блокируется. Остальные допустимые записи обрабатываются после проверок.

**Не удаляйте и не редактируйте `State`, не меняйте рабочие настройки и не запускайте
старую версию скриптов для обхода ошибки.** Файл `import.lock` остаётся на диске
штатно; удалять его не нужно.

## 4. Проверить результат

Код выхода `0` означает завершение сценария, `1` — ошибку выполнения,
`2` — ошибку параметров. При коде `0` отдельные проблемные записи могут быть пропущены:
обязательно проверьте итоговую строку в консоли или логе.

```text
Импорт 2026-10-08 завершён: начислено N, уже подтверждено M, пропущено из-за ошибок K, всего T.
```

`N` — новые пополнения этого запуска, `M` — уже подтверждённые начисления,
`K` — пропущенные записи CSV. Если `K` больше нуля, найдите причины пропуска в логе.
Если итоговой строки нет и есть `Сценарий остановлен`, полная обработка не подтверждена.

Лог повторного запуска: `app\main\Logs\YYYY-MM-DD_import-local.log`.
Дата в имени лога — **дата запуска**, даже если пополнение выполнялось за другой день.
После перехода в корень проекта посмотреть конец сегодняшнего лога можно так:

```powershell
Get-Content -LiteralPath ".\app\main\Logs\$(Get-Date -Format 'yyyy-MM-dd')_import-local.log" -Tail 80 -Encoding UTF8
```

## Если снова ошибка

| Сообщение | Действие инженера |
| --- | --- |
| `WinError 5 / Access is denied` при сохранении | Исправленная версия выдерживает 250 мс между заменами файлов и повторяет замену до 5 секунд. Если ошибка осталась, сохраните лог и передайте администратору или разработчику для проверки доступа и защитного ПО. Начисление перед ошибкой могло уже пройти; State сохраняйте. |
| Результат прежнего запроса неизвестен, повтор запрещён | Нужна сверка транзакций iiko по гостю, дате, сумме и маркеру операции. Не снимайте блокировку вручную и не используйте `resolve-refill` без подтверждённого результата сверки. |
| Другой процесс уже выполняет импорт или сверку | Дождитесь завершения другого запуска и повторите команду. Не удаляйте `import.lock`. |
| CSV не найден или ошибка чтения | Проверьте дату, имя, папку и кодировку файла. |
| Сетевая ошибка, ошибка авторизации или API iiko | Передайте точный текст ошибки ответственному за подключение. Уже выполненные начисления не откатываются. |

Для разбора передайте разработчику команду запуска, время ошибки, соответствующий лог,
копию журнала за нужную дату из `State` и исходный CSV. Не отправляйте рабочий
`config.local.json` с паролями.
